# 📊 Dashboard de Vendas Xbox & Gaming - Excel

Este repositório contém a solução do desafio de criação de um Dashboard de Vendas no Excel.

## 🎯 Objetivo
Transformar dados brutos de vendas em informações visuais claras, dinâmicas e estratégicas para tomada de decisão.

## 📁 Estrutura do Projeto
- `dashboard_vendas_xbox.xlsx`: Arquivo contendo a base de dados, abas de cálculos e o dashboard executivo com indicadores e gráficos.
- `README.md`: Documentação e explicação do projeto.

## 📈 Indicadores Analisados
- **Faturamento Total (R$)**
- **Volume de Unidades Vendidas**
- **Ticket Médio por Transação**
- **Lucratividade Total**
- **Desempenho por Categoria, Canal de Venda e Evolução Mensal**

## 🛠️ Tecnologias e Ferramentas
- Microsoft Excel / Excel Online
- Fórmulas Avançadas (`SOMASE`, `MÉDIA`, `CONT.VALORES`)
- Visualização de Dados (Gráficos de Linha, Colunas, Barras e Pizza)
